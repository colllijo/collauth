\doxysubsection{Detailed Description}
Abstract base class for elliptic curve cryptography. 

This class defines the interface for elliptic curves over a finite field, supporting both Weierstrass and Montgomery forms. The parameters ( a ) and ( b ) represent the curve parameters for either the Weierstrass form\+:   \[    y^2 = x^3 + ax + b \pmod{p}
\] or the Montgomery form\+:   \[    By^2 = x^3 + Ax^2 + x \pmod{p}
\] where ( a ), ( b ) (or ( A ), ( B )) are curve parameters and ( p ) is the prime modulus.
